# Aariyadhevan L — Portfolio

A responsive black-and-red portfolio website inspired by the uploaded visual reference.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, typography and animations
- `script.js` — mobile navigation, active section and reveal effects

## Run locally
Open `index.html` in a modern browser. No build step or framework is required.

## Publish with GitHub Pages
1. Create a GitHub repository named `portfolio-website` (or `AARIYADHEVAN.github.io` for a user site).
2. Upload all files while preserving the folder structure.
3. In repository Settings → Pages, select the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to deploy.

## Personalise before publishing
Update your project descriptions and add your real project repository links in `index.html`. Replace the LinkedIn and Instagram profile links with your profile URLs. Skill lists are editable placeholders; keep only technologies you can confidently discuss.
